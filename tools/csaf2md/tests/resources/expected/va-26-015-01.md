## VA-26-015-01

## NOAA PMEL Live Access Server (LAS) command injection

**[View Source](https://raw.githubusercontent.com/cisagov/CSAF/develop/csaf_files/IT/white/2025/va-26-015-01.json)**

## 1. EXECUTIVE SUMMARY

* **CVSS v3 9.8**
* **ATTENTION**: Exploitable remotely/low attack complexity
* **Vendor**: National Oceanic and Atmospheric Administration (NOAA)
* **Equipment**: (INSERT_EQUIPMENT_LIST) National Oceanic and Atmospheric Administration (NOAA) Live Access Server (LAS)
* **Vulnerability**: Improper Neutralization of Special Elements used in an OS Command ('OS Command Injection')

## 2. RISK EVALUATION

Sites running NOAA PMEL Live Access Server (LAS) are vulnerable to remote code execution via specially crafted requests that include PyFerret expressions. By leveraging a SPAWN command, a remote, unauthenticated attacker can execute arbitrary OS commands.

## 4. MITIGATIONS

National Oceanic and Atmospheric Administration (NOAA) has identified the following specific workarounds and mitigations users can apply to reduce risk:

* National Oceanic and Atmospheric Administration (NOAA) Live Access Server (LAS) 8: Users running LAS 8 should apply the fix as described at https://github.com/NOAA-PMEL/LAS/blob/main/README.md, which involves a version of 'gov.noaa.pmel.tmap.las.filter.RequestInputFilter.java' [from 2025-09-24.](https://github.com/NOAA-PMEL/LAS/blob/main/README.md)

The following product versions have been fixed:

- Live Access Server (LAS) 8 is a fixed version for CVE-2025-62193

For more information see the associated CISA security advisory VA-26-015-01 [Vulnerability Advisory VA-26-015-01 CSAF](https://raw.githubusercontent.com/cisagov/CSAF/develop/csaf_files/IT/white/2025/va-26-015-01.json).
